# GLPI Asset Management Deployment 📦
This repository contains a `docker-compose` stack to rapidly deploy GLPI (IT Asset Management & Helpdesk) along with its MariaDB database.

## Prerequisites
* Docker & Docker Compose installed on the host.

## Quick Start
1. Clone this repository.
2. Run `docker-compose up -d`.
3. Access GLPI via `http://<Server_IP>:8080`.
